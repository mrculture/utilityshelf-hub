Privacy

UtilityShelf is designed around lightweight tools. Individual tools should explain whether processing happens locally in the browser.

Hosting providers may receive standard technical request data such as IP address, browser, requested page, and time of visit.

We use Cloudflare Web Analytics to measure page visits and loading performance across UtilityShelf. Our analytics integration does not submit the contents you enter into our tools.

Filename Cleaner, Image Contact Sheet, Image Dimension Checker, CSV Import Checker, CSV Column Mapper and CSV Formula Checker also send limited usage events to Cloudflare Analytics Engine. These count valid filename lists, copies, mapping and renamed-photo ZIP download starts, photo reordering, contact sheet download starts, completed image checks, image check report download starts, use of the eBay preset on photos, completed CSV structure checks, corrected CSV download starts, completed column mappings, mapped CSV download starts, completed formula-prefix scans and CSV check report download starts. A download event means the browser started a download, not that a file was saved. Each event contains only the tool, action, a fixed mode label, and whether the built-in sample or custom input was used. It contains no filenames, prefixes, file contents, user identifiers or referrer URLs. We do not set cookies or store identifiers for these events. Cloudflare receives standard network request information to deliver the service; our event dataset does not store IP addresses or request headers. Events are retained by Analytics Engine for up to three months and may be sampled.

You can disable these usage events using the checkbox on each tool page. The choice lasts for that page load. These events also respect your browser’s Do Not Track and Global Privacy Control signals. Repeated actions are limited per page load; the counts measure usage events, not unique people. Sample events are reported separately from custom-input events. On Filename Cleaner, the two image tools and the three CSV tools, opening a test-mode link disables action events and the page-view beacon for that page; the page displays a Test mode notice.

Some guide pages may contain links to third-party websites or services. If a link is an affiliate or referral link, the third-party service may use cookies or similar technologies after you click the link to attribute the referral. UtilityShelf does not control those third-party sites or their privacy practices.

UtilityShelf may earn a commission from some third-party links at no extra cost to you. Affiliate relationships should not change the free browser-first utility experience.
