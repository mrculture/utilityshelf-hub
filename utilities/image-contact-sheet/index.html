File preparation

Image Contact Sheet

Make a downloadable PNG sheet of product photos with numbered filename captions. Review a batch without opening each file individually.

Photos to review

Select up to 24 JPEG, PNG or WebP files, up to 32 MB each. Photos are arranged in the order supplied by the file picker, with a number you can match to the filename list below.

Contact sheet preview

Choose photos or try the example.

    Review the batch before you send it

    Try the three example views, switch to two columns, and download the sheet. Ask a reviewer for a change to “02” and use the filename list to locate that photo.

    The sheet fits each image inside its cell without cropping. Long captions are shortened on the image; the list preserves the full names. Transparent areas appear white in the thumbnails.

    For submission checks, check the original image dimensions.

    Processing takes place on this device. Files you select stay in your browser.
