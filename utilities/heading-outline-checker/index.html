      Read the outline

      Read the headings as a table of contents. Going from H2 straight to H4 can leave a missing section level. Returning from H4 to H2 can simply close a subsection.

      The checker reads native H1–H6 elements from the supplied markup. It skips explicitly hidden content and template contents. Stylesheets, JavaScript-generated content, ARIA heading roles and a full accessibility-tree evaluation are outside this check. For a fragment, review the surrounding document before acting on H1 advice.
