File Checksum Checker

Calculate the SHA-256 checksum of a local file. Compare it with an expected hash to check whether a download or export matches byte for byte.

File to verify

Up to 64 MiB. Your browser reads the complete file into memory to calculate SHA-256.

SHA-256 result

Choose a file or try the example.

Check a download or an exported CSV

Use the checksum supplied by a source you trust. Select your downloaded copy and paste the expected 64-character digest. A match verifies the bytes against that reference. It does not establish who created the file or whether its contents are safe.

The example uses the three bytes of abc with no newline. Edit the last digit of the expected digest to see a mismatch. Changing a CSV's encoding or line endings also changes the hash, even when the cells look the same.

To check the structure of a spreadsheet export, open CSV Import Checker.

Processing takes place on this device. Files you select stay in your browser.
