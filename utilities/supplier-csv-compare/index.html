How matching works

SKUs match exactly, including capitals, spaces and leading zeros. For example, 0012 and 12 are different products. Each file needs one nonblank row identifier per product. Resolve blank or repeated SKUs before comparing.

Prices use non-negative digits with an optional decimal point, and stock uses whole numbers. Use the same currency and stock units in both files. 7.50 and 7.5 compare as equal, while a blank cell is different from zero.

Check the source files before acting on a difference. A missing SKU may mean the latest CSV covers a different set of products.

If the latest export includes product barcodes, check its barcode column before importing.
