Reuse a saved mapping

Open or paste the current CSV first, then load your saved mapping to restore the destination headings and column choices. Review the choices before building the export.

Mapping files are read locally (up to 64 KiB). Reordered columns are matched by exact header name. Added, missing or renamed headers require a new mapping; case and spaces must match.

Choose source columns

Each destination column needs a selection. Select “Use empty values” only when your importer accepts a blank column. Source columns you leave unused are excluded.

Choose every destination column to save a mapping. Reusable mappings require distinct, nonblank source headers. The downloaded JSON contains headers and column choices only, not data rows. Keep it on your device and review its headings before sharing.

Try a supplier feed

The example sends Stock code to SKU, Supplier title to Title and Unit cost to Price. The supplier’s internal note drops out. A code such as 0012 retains its leading zeros in the file; choose a text column when opening it in a spreadsheet.

Paste the exact headings from your destination’s own template. The tool checks field counts and quoting; importer-specific required values still need review. Formula-like input values are preserved. Check formula prefixes before sharing an export.
