Reuse a saved mapping

Open or paste the current CSV first, then load your saved mapping to restore the destination headings, column choices, required-field choices, duplicate-check settings and numeric rules. Review the choices before building the export.

Mapping files are read locally (up to 64 KiB). Reordered columns are matched by exact header name. Added, missing or renamed headers require a new mapping; case and spaces must match.

Choose source columns

Each destination column needs a selection. Select “Use empty values” only when your importer accepts a blank column. Source columns you leave unused are excluded.

Tick Required value for each destination column that must contain a value, then build the CSV. Empty and whitespace-only values are flagged; 0 and 0.00 count as present. These checks do not change the CSV. Required choices start off for a new setup, source CSV, destination header or sample. Save mapping includes these choices; Load mapping restores them for each destination column, even when source columns have moved. Older version 1 files load with all required choices off. Review them before building.

Price and stock formats

Choose a Numeric rule only for columns you want to validate. Price accepts non-negative digits and an optional dot decimal, with digits on both sides (for example 0, 0.00 or 12.50). Stock accepts non-negative whole-number digits, including 0; 2.0 and 2.5 are both flagged. Signs (including -0 and +1), currency symbols, grouping separators, decimal commas and exponent notation are not accepted. Outer whitespace is ignored only for validation; internal spaces are not allowed.

Blank and whitespace-only cells are skipped by numeric rules; tick Required value if the column must be populated. No values are rounded, filled or rewritten. These checks do not verify currency, maximum amounts, decimal precision or actual stock availability. Rules save with mappings and restore by destination column. Older mappings start with numeric rules off; a new setup, source CSV, destination header or sample resets them.

Duplicate comparison options

Tick Check duplicates for SKU or another destination column. Each selected column is checked separately. Both options start off: comparisons are exact and case-sensitive. Ignoring whitespace trims only the ends for comparison; internal spaces stay significant. Values remain text, so 0012 and 12 are different. Blank and whitespace-only cells are skipped; use Required value to flag them. No rows or values are edited or removed.

Save mapping includes duplicate selections and both options. Load mapping restores them for destination columns even if source columns move. Older mappings start with duplicate checks off. A new setup, source CSV, destination header or sample resets these settings.

Choose every destination column to save a mapping. Reusable mappings require distinct, nonblank source headers. The downloaded JSON contains headers, column choices, required-field, duplicate and numeric rules, not data rows. Keep it on your device and review its headings before sharing.

    Review flagged values before importing. Downloads stay available so you can save and correct the mapped file. Data rows exclude the header; CSV records include it.
