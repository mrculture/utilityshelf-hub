Import checks

Open a file, paste CSV, or try the sample.

    Run a check to create a report.

    The report includes the result, issue locations and suggested fixes. It lists up to 100 issues and states when more were found. Review issue details before sharing.

    Edit the CSV above and run Check CSV. When the header and field-count checks pass, download the exact checked text as a separate file. Values and formula-like fields are not changed automatically.

    Header comparisons ignore case and outer spaces. Line numbers refer to the pasted text, including the header. Quoted fields may contain commas and line breaks.
