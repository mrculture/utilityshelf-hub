Prepare product-photo filenames in four steps

  1. Use Load filename list to open the ordered text file from Contact Sheet, or paste the original filenames one per line. Leave out folder paths.
  2. Choose Clean existing names to keep descriptive words, or Product / SKU + numbers for an ordered photo set. For example, use the prefix SKU-1042, start at 1 and choose three digits.
  3. Review the suggestions. Resolve highlighted duplicates or invalid names; the final list appears only when every name is ready.
  4. Copy or select the final list and download the filename mapping. Use the numbered original/new pairs to match each file when applying the names in your file manager or renaming tool.

Filename questions

Does this rename or upload my files?

Your originals are never renamed or uploaded. Pasting names produces a reviewed list and mapping. If you also select photos, the browser reads them locally and creates a ZIP of renamed copies with identical image bytes. Extract it into a new folder before using the copies.

Why are two differently capitalised names duplicates?

Some file systems treat capitalisation as equivalent. This tool compares names without case differences and with Unicode normalisation to help you avoid collisions.

Can I use spaces, accents and mixed file types?

Yes. Choose spaces, hyphens or underscores between words. Accented letters are preserved, as is each final extension, such as .JPG or .png. Folder paths, Windows reserved names and unsupported characters are flagged. A filename longer than 255 UTF-8 bytes is also flagged; your destination may have stricter limits.

Does a clean filename guarantee search rankings?

No. Descriptive names help you organise your photos. Product-page content, image quality and the requirements of your publishing platform still matter.
