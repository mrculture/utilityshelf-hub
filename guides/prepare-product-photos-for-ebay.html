How to prepare product photos for an eBay listing

· Privacy

A useful listing photo set needs clear views, suitable image sizes and a predictable order. Take six illustrative photos through three UtilityShelf tools and finish with checked photos, reports, a contact sheet and ZIP of SKU-named copies, including their filename mapping.

Start with the original photos

These tools check, resize, arrange and create renamed copies locally. They do not upload pictures to eBay or change your original files. If resizing is needed, extract the new copies first, then select those same checked files separately in each remaining tool. If your photos already meet your limits, keep them as they are.

Check photo dimensions

Use batches of up to 30 photos, 32 MB per photo and 100 MB combined across all three tools (1 MB = 1,000,000 bytes). If you select 31 or more photos, or exceed 100 MB combined, split the batch and select it again. The tools reject oversized batches without silently dropping the extra photos. Resizing also has the pixel limits shown in Image Dimension Checker.

Try a downloadable practice batch

Download practice photo pack (.zip)

This pack contains six synthetic test files, a replacement photo, practice-settings.json and START-HERE.txt. One test file is deliberately unreadable. The examples are illustrations, not real product photos. This exercise starts with six files and finishes with five checked photos; it is separate from the six-view listing example below.

  1. Extract the ZIP into a new folder. Open Image Dimension Checker in practice mode and use Load settings to select practice-settings.json. These custom practice limits are 800 × 800 px minimum, 1 MB maximum and a 1200 px maximum long edge, not eBay requirements. Practice mode excludes your test actions from usage counts.
  2. Choose only the six files in the photos folder. Expect 3 of 6 meet your limits and a report marked Check incomplete. The maximum long edge applies when preparing copies, rather than to the initial dimension check.

1. Check sizes and download the photo report

Choose your JPEG, PNG or WebP photos in Image Dimension Checker. Select eBay — recommended size. UtilityShelf checks for at least 1600 pixels in both dimensions and a maximum of 12 MB per photo; a rectangular image can pass without a square crop.

For example, a 4000 × 2992 JPEG at 2.8 MB passes these size checks. A 1600 × 900 image falls short of this preset's height target. That result does not, by itself, mean eBay will reject it: this is a recommended-size check, not a complete acceptance test.

  1. Wait for the results, then select Download photo report (.txt). Save image-dimension-report.txt with your listing notes. It records the current limits and puts photos needing attention first, with original filenames, dimensions, exact file sizes and reasons; passing photos appear separately.
  2. Review every flagged photo. An unreadable file makes the report Check incomplete; it is not a pass. Use Replace on that row to choose another photo and check it in the same position, or Remove to leave it out. Other photos stay in the batch and your originals stay untouched. Review the updated totals and download a fresh report.
  3. Download a fresh report after replacing photos or changing limits. For a practice check, a 2.8 MB photo exceeds a custom 2.5 MB limit even though it passes the eBay size preset. Restore the limits you intend to use before saving your final report.

The report button is unavailable while photos are loading or limits are invalid. Review filenames before sharing the report; it contains no photo contents.

Removing or replacing a photo clears any prepared resized download. Select Prepare smaller copies again when the batch is ready. A replacement that would exceed 100 MB combined is rejected and the previous batch stays unchanged; an unreadable replacement appears as a failed check. Cancelling the file picker leaves the photo unchanged. If you remove every photo, choose a new batch to continue.

Carry only the final remaining photos into the next tools. If you replaced a photo, use its new filename in place of the old one. When you download checked copies, the ZIP contains the current batch, including replacements and excluding removed photos.

2. Resize oversized photos when needed

In Image Dimension Checker, use Make smaller photo copies with your chosen minimum dimensions and maximum file size. Optionally set Maximum long edge (for example, 2400 pixels), then select Prepare smaller copies. It never enlarges or crops photos. If a photo is already too small, or the limits cannot be met, resolve the issue before downloading.

Review the previews and before/after measurements, then select Download checked copies (.zip). The ZIP includes the complete checked batch and resize-report.txt. Modified images are lossy JPEGs with transparent areas placed on white and original EXIF metadata omitted. Photos already within the limits keep their original bytes and metadata. Extract into a new folder and use these checked copies, with their new filenames, for the remaining steps. Your originals remain untouched.

For a practice batch of 4000 × 2992 photos, choose a minimum of 1600 × 1600, a maximum size of 2.5 MB and an optional maximum long edge of 2400 pixels. These are custom workflow settings, not eBay requirements. The proportional target is 2400 × 1795; if meeting the byte limit needs further reduction, the minimum dimensions still apply.

To reuse these limits, select Save settings under the maximum long edge field. Keep image-dimension-settings.json and use Load settings on a later visit. It saves the preset, minimum dimensions, maximum file size and optional maximum long edge, with no photos or filenames. Load your photos separately. Loading valid settings rechecks the current batch and clears any prepared resized ZIP; prepare the copies again and save a fresh photo report. An invalid settings file leaves the existing limits and results unchanged.

  1. Extract checked-photo-copies.zip into a separate folder. Keep resize-report.txt: it connects the source names to the checked-copy names and records before/after dimensions and sizes.
  2. Choose the extracted photos again in Image Dimension Checker with the limits you intend to use. Confirm every photo passes, then download a fresh image-dimension-report.txt. The earlier report describes the earlier input files.
  3. Use these extracted filenames in the contact sheet and Filename Cleaner. For example, front.jpg might become 01-front-resized.jpg. Keep that current name until the SKU naming step. Do not mix the camera originals with the checked copies.

If you start with already-resized photos that pass your chosen limits, skip creating another checked-copy ZIP. Save their current photo report and continue with those files.

Inspect focus, glare, colour and whether the photo accurately shows the item. Check the current eBay photo guidance for its own requirements and tips. Guidance checked 10 November 2026.

3. Choose the listing order

Open Image Contact Sheet and choose the final checked files again, including any resized copies or replacements. Use Move earlier and Move later to put a clear main view first. Supporting views should explain what is included, show useful details and reveal any defects. The best order depends on the item.

4. Transfer the order and create SKU names

  1. Select Download ordered filenames (.txt) in Contact Sheet to save ordered-filenames.txt. Alternatively, use Copy filenames in this order, or Select all filenames and Ctrl+C / ⌘C.
  2. Open Filename Cleaner, select Load filename list and choose that text file, or paste into Original filenames. Loading replaces the list, keeps your naming settings and regenerates suggestions. Here, “Original filenames” means the current names of the checked files, including resized-copy names. The text file contains names only; select the matching photos separately when preparing the ZIP.
  3. Choose Product / SKU + numbers, enter SKU-1042, start at 1, select 3 minimum digits and use lowercase with hyphens.
  4. Review all six names. The tool preserves extension case, so a source ending in .JPG keeps .JPG.
  5. Confirm that the final list contains all six names in your chosen order. You can copy it or download the mapping separately; the next step also includes that mapping inside the photo ZIP.

5. Download the renamed-photo ZIP

  1. In Filename Cleaner, find Download renamed photo copies and choose the same six checked files using Original photos for the ZIP. If you resized earlier, select those extracted resized copies here. Match every current filename in your reviewed list exactly, including spelling and case. File-picker order does not matter.
  2. Wait for 6 photos matched by original filename. If files are missing, extra or ambiguously named, correct the selection or list first. The download stays unavailable until every photo has a unique match and every proposed name is valid.
  3. Select Download renamed photos (.zip). Save renamed-photos.zip alongside the photo report and contact sheet. It contains the six reviewed names, from sku-1042-001.jpg to sku-1042-006.jpg in this example, plus filename-mapping.txt.
  4. Extract the ZIP into a new listing folder. Open the copies and compare them with the contact sheet and mapping. Filename Cleaner preserves the exact bytes and metadata of the checked files you selected. Any earlier resizing has already changed those copies; the SKU-naming step does not recompress them. Camera originals remain untouched.

Keep the latest photo report, contact-sheet PNG and renamed-photo ZIP together. The mapping inside the ZIP connects checked-file names to SKU names. Keep the resize report too when applicable: together the two mappings trace camera-original → checked copy → SKU name. Reports follow selection order; match by filename rather than row number.

If you change the listing order, download and load the new filename list (or copy it again), then download a fresh contact sheet and ZIP. Filename lists use UTF-8 text, one name per line, with no folder paths. Blank lines are ignored; spelling, case and order are preserved. Invalid imports leave the previous list unchanged. Changed photos also need a fresh size check and report; changed size limits need a fresh report. Loading a new list or editing names or selected files while a ZIP is being prepared cancels that pending ZIP.

The ZIP supports up to 30 JPEG, PNG or WebP photos, 32 MB each and 100 MB combined. For other file types or larger batches, use the mapping in your file manager or renaming application. Do not assume the file manager's sort order matches the contact sheet. Neither the copied list nor the mapping download alone renames anything automatically.

6. Verify the listing photos

Upload the extracted checked, SKU-named photos to your listing, not the ZIP or contact-sheet PNG. Verify the main photo and order in eBay's editor. Numbered filenames help you organise the set, but the uploader may choose a different order. Review the completed listing before publishing.
