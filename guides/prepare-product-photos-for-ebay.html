How to prepare product photos for an eBay listing

A useful listing photo set needs clear views, suitable image sizes and a predictable order. This walkthrough takes six illustrative photos through three UtilityShelf tools. Keep your originals and work with copies when you apply the final names.

Start with the original photos

These tools check, arrange and name your files locally. They do not upload pictures to eBay or rename files on your device.

Check photo dimensions

1. Check sizes and download the photo report

Choose your JPEG, PNG or WebP photos in Image Dimension Checker. Select eBay — recommended size. UtilityShelf checks for at least 1600 pixels in both dimensions and a maximum of 12 MB per photo; a rectangular image can pass without a square crop.

For example, a 4000 × 2992 JPEG at 2.8 MB passes these size checks. A 1600 × 900 image falls short of this preset's height target. That result does not, by itself, mean eBay will reject it: this is a recommended-size check, not a complete acceptance test.

  1. Wait for the results, then select Download photo report (.txt). Save image-dimension-report.txt with your listing notes. It records the current limits and puts photos needing attention first, with original filenames, dimensions, exact file sizes and reasons; passing photos appear separately.
  2. Review every flagged photo. An unreadable file makes the report Check incomplete; it is not a pass. Choose a readable replacement or resolve the issue, then check the final batch again.
  3. Download a fresh report after replacing photos or changing limits. For a practice check, a 2.8 MB photo exceeds a custom 2.5 MB limit even though it passes the eBay size preset. Restore the limits you intend to use before saving your final report.

The report button is unavailable while photos are loading or limits are invalid. It does not resize images. Review filenames before sharing the report; it contains no photo contents.

Inspect focus, glare, colour and whether the photo accurately shows the item. Check the current eBay photo guidance for its own requirements and tips. Guidance checked 10 November 2026.

2. Choose the listing order

Open Image Contact Sheet and choose the final checked files again, including any replacements. Use Move earlier and Move later to put a clear main view first. Supporting views should explain what is included, show useful details and reveal any defects. The best order depends on the item.

3. Copy the order and create SKU names

  1. Select Copy filenames in this order. If automatic copying is unavailable, use Select all filenames and press Ctrl+C or ⌘C.
  2. Open Filename Cleaner and paste into Original filenames. The list should contain exactly the views you chose, one name per line.
  3. Choose Product / SKU + numbers, enter SKU-1042, start at 1, select 3 minimum digits and use lowercase with hyphens.
  4. Review all six names. The tool preserves extension case, so a source ending in .JPG keeps .JPG.
  5. Copy the final list and download the filename mapping. Reordering the contact sheet later means copying its updated list and generating a fresh mapping.

4. Rename copies and verify the listing

Keep three downloads together: the latest photo report for size findings, the contact-sheet PNG for the chosen view order, and the filename mapping connecting original names to SKU names. The report uses the original names and selection order; use the mapping to identify the renamed copies, not matching row numbers. Changing only the listing order needs a fresh contact sheet and mapping, while changed photos or size limits also need a fresh report.

In Filename Cleaner, select your original photos under Download renamed photo copies, then select Download renamed photos (.zip). Every file must match an original filename in the reviewed list exactly; file-picker order does not matter. The ZIP contains the renamed copies and filename-mapping.txt. Extract it into a new listing folder and check each pairing. Photo bytes and embedded metadata are unchanged; originals are never renamed or uploaded.

The ZIP supports up to 30 JPEG, PNG or WebP photos, 32 MB each and 100 MB combined. For other file types or larger batches, use the mapping in your file manager or renaming application. Do not assume the file manager's sort order matches the contact sheet. Neither the copied list nor the mapping download alone renames anything automatically.

Upload the full-size copies to your listing and verify the main photo and order in eBay's editor. Numbered filenames help you organise the set, but the uploader may choose a different order. Review the completed listing before publishing.
